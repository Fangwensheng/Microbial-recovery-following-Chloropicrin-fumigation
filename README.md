# Microbial recovery following Chloropicrin fumigation
R scripts and intermediate datasets for reproducing all main figures and supplementary figures of the manuscript about microbial community recovery after chloropicrin soil fumigation.

## Project Overview
This repository contains reproducible R code and curated intermediate data used to generate all main and supplementary figures.
- `00_*.R`: Preprocessing and re-computation scripts (cross-domain bootstrap, DESeq2, KO trajectory analysis, taxonomic composition metrics, MAG provider trait analysis)
- `01_Figure1.R ~ 15_FigureS8.R`: Independent plotting scripts for each main figure and supplementary figure
- Intermediate raw tables, MAG metadata, and per-panel plotting CSV files are provided for direct figure reproduction.

> **Raw sequencing reads (amplicon & metagenomics) are NOT deposited here.**
> Raw sequencing data have been submitted to GSA/SRA. Please replace this line with your final accession number upon acceptance.
